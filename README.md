# Language Translation Tool - Streamlit

Run locally:
```bash
pip install -r requirements.txt
streamlit run app.py
```

Deploy on Streamlit Community Cloud:
1. Upload `app.py` and `requirements.txt` to GitHub.
2. Open https://share.streamlit.io/
3. Sign in with GitHub.
4. Create a new app.
5. Select the repository, branch, and `app.py`.
6. Deploy.

The app uses MyMemory by default, so no API key is required for this demo.
